# FreeTools BD — Starter Website

This is a zero-cost starter static website with:
- Image Resizer
- Image Compressor
- Word Counter
- Case Converter
- Percentage Calculator
- Age Calculator

## Run locally
Open index.html in a browser.

## Free publishing
You can publish this static website using a free static hosting service such as GitHub Pages. No paid hosting is required for this starter version.

## Before publishing
1. Replace the placeholder contact text with your email.
2. Add Privacy Policy and Terms pages before monetization.
3. Add more genuinely useful tools.
4. Do not use fake traffic, auto-refresh, forced ad clicks, or other invalid traffic methods.
